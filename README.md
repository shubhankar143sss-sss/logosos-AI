# Logos OS

Open designs and code for **governed AI systems**: AI models propose, deterministic code decides, humans keep authority.

By **Shubhankar Sharma**. Free to read, use and build on, with credit.

| Folder | What it is |
|---|---|
| [`acp/`](acp/) | **ACP, the Authority Control Protocol.** Specification plus a TypeScript reference kernel with tests and a demo. Apache-2.0. |
| [`research/`](research/) | Readable notes on the wider architecture: kernel, memory and cost routing, governance stacks, world-model evidence, calibration. CC BY 4.0. |

## Where to start

1. Run the demo in [`acp/`](acp/): `npm install && npm run demo`.
2. Read the [ACP spec](acp/spec/ACP-v3.0-Specification.md).
3. Read the [research overview](research/01-overview.md).

## Honesty note

These are drafts by one author. Nothing here is audited or independently reviewed, and the research notes separate what could be built today from what is speculative. If you find a flaw, please open an issue.
