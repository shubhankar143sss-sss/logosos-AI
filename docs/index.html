What is here

ACP: Authority Control Protocol

A draft protocol and TypeScript reference kernel. Agents send signed proposals; the kernel checks signed, expiring permissions, limits, delegation depth and idempotency, and requires a human signature for irreversible actions.

Spec, code, tests and demo

Research notes

Readable write-ups of the wider architecture: kernel, memory and cost routing, governance stacks, world-model evidence and calibration. Each separates what can be built now from what is speculative.

Try it in two minutes

Needs Node 20 or newer:

git clone https://github.com/shubhankar143sss-sss/logosos-AI
cd logosos-AI/acp && npm install && npm run demo

Status, plainly

  • ACP is a draft. It is not audited and not a standard.
  • The reference kernel keeps state in memory and has no network server yet.
  • The most useful help: try to get the kernel to allow something it should not, and open an issue with a failing test.
